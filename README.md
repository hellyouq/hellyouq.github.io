# 🫧 Liquid Glass — сайт, который собирается на ходу

Статический сайт для GitHub Pages, который **на каждом заходе** обращается к Gemini API и
заново придумывает себя: название, палитру, тексты, разделы, мини-игры и одну игру-сюрприз,
код которой пишется моделью тут же. Оформление — в духе iOS «liquid glass»: размытие,
прозрачность, мыльные блики и медленные плавные анимации.

> Обнови страницу — получишь другой сайт. Сборка идёт в браузере, бэкенда нет.

## Как это выглядит

1. Открываешь страницу — видишь стеклянную «сборку»: прогресс, этапы («Подбираю палитру и
   стекло», «Пишу игру-сюрприз»), название, которое модель успела придумать.
2. Через 15–25 секунд сборка растворяется и появляется готовый сайт: своя тема, свой герой,
   свои разделы и игры.
3. Если сеть или модель подвели — сайт всё равно соберётся локально, без ИИ (кнопка появляется
   автоматически).

## Как это работает

```
браузер
  ├─ prompt.js   собирает большой промт: правила, схема JSON, каталог игр, требования к стилю
  ├─ gemini.js   POST streamGenerateContent?alt=sse — стриминг, чтобы показывать живой прогресс;
  │              при 429/5xx/таймауте берёт следующую модель из списка
  ├─ spec.js     нормализует ответ: чинит типы, зажимает параметры в диапазоны, отбрасывает
  │              небезопасный HTML, добирает недостающие разделы, умеет собрать сайт без ИИ
  ├─ render.js   превращает «спеку» в DOM: навигация, герой, разделы, карточки игр, футер,
  │              параллакс фона, появление по скроллу — и следит, чтобы один сбой не унёс страницу
  ├─ games.js    14 движков мини-игр + «оболочка» карточки (счёт, рекорд, полноэкранный режим)
  ├─ widgets.js  11 неигровых активностей (рисование, задания, новости, дыхание, пианино…)
  └─ main.js     загрузочный экран, история сайтов, ссылка-поделиться, настройки, горячие клавиши
```

Ключевое: **модель не пишет вёрстку страницы**. Она отдаёт компактную «спеку» — JSON с темой,
текстами и списком активностей, — а вёрстку собирает проверенный локальный код. Поэтому даже
странный ответ модели превращается в аккуратный сайт, а не в кашу из HTML.
Единственное исключение — игра-сюрприз: её HTML пишет модель, но запускается он в песочнице
(`sandbox="allow-scripts"`, без доступа к родительской странице) и с аварийной заглушкой.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | каркас: контейнер `.lg-app`, загрузочный экран, подключение скриптов |
| `404.html` | та же сборка для несуществующих адресов GitHub Pages |
| `css/app.css` | вся «стеклянная» система: стекло, блики, пузыри, анимации, адаптив, светлая тема |
| `js/config.js` | ключ, список моделей, температура, лимиты, ключи localStorage |
| `js/prompt.js` | промт для Gemini: схема, правила, каталог игр, требования к игре-сюрпризу |
| `js/gemini.js` | клиент API: стриминг, перебор моделей, разбор и починка JSON |
| `js/spec.js` | каталог игр, нормализация ответа модели, локальный фолбэк, кодек ссылок |
| `js/render.js` | сборка интерфейса из спеки |
| `js/games.js` | 14 игр и общая оболочка карточки |
| `js/widgets.js` | 11 активностей и песочница для игры-сюрприза |
| `js/main.js` | загрузочный экран, генерация, история, панель настроек, поделиться |
| `js/extras.js` | заготовки текстов для локального режима (факты, цитаты, задания) |
| `tests/*.mjs` | тесты: нормализация, клиент Gemini, сверка CSS-классов |

Сборка не нужна: это обычные `<script>`, глобальное пространство `APP`, никаких зависимостей.

## Публикация на GitHub Pages

1. Скопируй содержимое папки в репозиторий вида `<логин>.github.io`.
2. Запушь в ветку `main`.
3. В настройках репозитория → **Pages** → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
4. Открой `https://<логин>.github.io/` — сайт соберётся сам.

Сайт работает и при открытии файла с диска (`file://`), но по-хорошему ему нужен `http(s)`:
так доступны `localStorage`, ссылки-поделиться и установка как PWA.

## ⚠️ Безопасность ключа и прокси

Ключ лежит в `js/config.js` — то есть **виден любому, кто откроет исходники сайта**. Это
нормально только для демо-ключа с выставленными квотами. Для платного ключа обязательно
поставь прокси:

1. Возьми готовый Cloudflare Worker и замени `GEMINI_KEY` на свой ключ:

```js
// воркер: POST https://<имя>.<логин>.workers.dev/generate?model=gemini-3.8-flash
export default {
  async fetch(req, env) {
    const cors = {
      'access-control-allow-origin': '*',
      'access-control-allow-methods': 'POST, OPTIONS',
      'access-control-allow-headers': 'content-type'
    };
    if (req.method === 'OPTIONS') return new Response(null, { headers: cors });
    const model = new URL(req.url).searchParams.get('model') || 'gemini-3.8-flash';
    const r = await fetch(
      `https://generativelanguage.googleapis.com/v1beta/models/${model}:streamGenerateContent?alt=sse`,
      {
        method: 'POST',
        headers: { 'content-type': 'application/json', 'x-goog-api-key': env.GEMINI_KEY },
        body: await req.text()          // тело уходит как есть
      }
    );
    return new Response(r.body, {
      status: r.status,
      headers: { ...cors, 'content-type': r.headers.get('content-type') || 'text/event-stream' }
    });
  }
};
```

2. В `js/config.js` впиши адрес воркера и очисти ключ:

```js
API_KEY: '',
PROXY_URL: 'https://<имя>.<логин>.workers.dev',
```

Ключ можно подменить и без правки файлов — из консоли браузера:

```js
localStorage.setItem('liquidglass.key', 'НОВЫЙ_КЛЮЧ');   // перезагрузить страницу
```

Снимается так же: `localStorage.removeItem('liquidglass.key')`.

## Модели и настройки

Список моделей — `MODELS` в `js/config.js`. Они перебираются по порядку: если модель ответила
`429`, `404`, `5xx` или таймаутом, запрос уходит к следующей; пользователь видит это в этапах
сборки. Проверено на живом ключе (по состоянию на октябрь 2026):

| Модель | Статус |
|---|---|
| `gemini-3.1-flash-lite` | ✅ **основная**: сайт за ~6 с, спека компактнее |
| `gemini-3.8-flash` | ✅ запасная: тексты богаче, но ~20–25 с |
| `gemini-3.5-flash`, `gemini-flash-latest` | ✅ вторая линия обороны |
| `gemini-4-argon`, `gemini-pro-latest` | ⚠️ `429`: у бесплатного ключа нет квоты |
| `gemini-2.5-flash` | ❌ `404`: «no longer available to new users» |

Лёгкие модели пишут спеку примерно вдвое короче, поэтому оценка длины ответа (и шкала этапов
сборки) зависит от модели: `estFor()` в `js/gemini.js` даёт для `*-lite` 3400 символов,
для остальных — 6800. Иначе полоска прогресса замирала бы на середине.

Прочее в конфиге:

- `TEMPERATURE: 1.2` и `TOP_P: 0.95` — чтобы каждый заход был заметно другим.
- `THINKING_LEVEL: 'low'` — быстро. `'high'` даёт более складные сайты, но заметно дольше.
  3.x-модели получают `thinkingLevel`, ветка 2.5 — `thinkingBudget`; **оба ключа сразу API
  отклоняет с ошибкой 400**, поэтому отправляется ровно один.
- `MAX_OUTPUT_TOKENS: 20000` — с запасом на игру-сюрприз.
- `TIMEOUT_MS: 90000` — сколько ждём одну модель, прежде чем взять следующую.

## Что умеет генерируемый сайт

**Мини-игры** (модель выбирает из каталога, максимум 5 в одном разделе):

🐍 стеклянная змейка · 🧼 2048 · 🧠 пары · ⚡ реакция · 🧱 разбей витрину · 🫧 пузырь вверх ·
🎵 эхо (Simon) · ❌ крестики-нолики против ИИ · 💣 минное поле · 🏗️ башня · 🎯 тир ·
🌈 цветные слова (Струп) · ⌨️ скорость печати · 💡 огни

У каждой карточки — счёт, рекорд в `localStorage`, кнопка «Во весь экран» (выход по `Esc`).
Клавиатуру слушает только та игра, в которую ты последний раз ткнул, — соседние карточки
не дёргаются.

**Активности:** рисование со свечением и экспортом в PNG · задания с опытом и прогресс-кольцом ·
выдуманные новости · карточки-факты с переворотом · цитаты · дыхательная практика · помодоро ·
колесо решений · стеклянное пианино · питомец-блоб с пружинной физикой · прогресс по рекордам.

**Игра-сюрприз:** одна уникальная мини-игра, HTML которой модель пишет с нуля под тему сайта
(например, «Ловец Жемчуга» на сайте про море). Работает в изолированном `iframe`: без доступа
к странице, с аварийной заглушкой, если что-то не запустилось.

Ограничения дизайна (сознательные): 4–7 разделов плюс сюрприз, не больше 5 игр в разделе,
и хотя бы один раздел с играми. Так страница остаётся лёгкой и не превращается в свалку.

## Ссылки-поделиться и история

- Кнопка 🔗 сжимает всю спеку (gzip + base64url) в адрес: `…/#s=…`. Открытый по такой ссылке
  сайт показывается ровно таким, каким его собрали, — без обращения к API. Если спека слишком
  длинная, из ссылки выкидывается игра-сюрприз.
- Кнопка 🎲 открывает панель: можно написать пожелание («сайт про котиков-космонавтов»), выбрать
  готовый чип или собрать сайт локально без ИИ. Там же — переключатели «меньше анимаций» и
  «без звука».
- Уже собранные сайты складываются в историю (5 штук) и открываются одним кликом.
- Пожелание можно передать и через адрес: `…/?vibe=аквариум`.

## Тесты

Нужен только Node.js, зависимостей нет:

```bash
node --check js/gemini.js          # синтаксис любого файла
node tests/test-spec.mjs           # каталог, нормализация, фолбэк, ссылки      →  9/9
node tests/test-gemini.mjs         # стриминг, модели, thinkingConfig, прокси   → 10/10
node tests/check-classes.mjs       # каждый класс из разметки описан в CSS     → 228/228
```

Тесты проверяют в том числе, что мусорный ответ модели превращается в рабочий сайт, что
опасный HTML сюрприза отбрасывается, что параметры игр зажимаются в диапазоны и что ключ уходит
в заголовке `x-goog-api-key`, а не в адресе.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| «Модель не ответила» | Квота или сеть. Кнопка «Собрать локально, без ИИ» соберёт сайт без запроса; «Попробовать снова» — повторит. |
| Долго висит на «Соединяюсь с генератором» | Первая модель недоступна, идёт перебор. Можно поставить `THINKING_LEVEL: 'low'` и убрать тяжёлые модели из `MODELS`. |
| Сайт собрался, но пусто | Раздел не завёлся — на его месте будет пометка, остальное работает. Обнови страницу: следующий сайт будет другим. |
| Игра-сюрприз не запустилась | Так бывает, если модель написала код с ошибкой: появится заглушка и кнопка «Перезапустить». |
| Хочется вернуть сайт | Кнопка 🎲 → «Недавние сайты». Или ссылка-поделиться, если сохранил её. |

Сайт, который ты сейчас читаешь в браузере, никогда не бывает одинаковым дважды — в этом и
смысл. 🫧
